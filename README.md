# Smart Prompt Studio

## Description
Smart Prompt Studio is a Python application that helps users generate, improve and save AI study prompts.

## Features
- Generate study prompts
- Improve existing prompts
- Save prompts to a text file
- View saved prompts

## Technologies Used
- Python
- File Handling
- Functions
- Loops
- Exception Handling

## How to Run
1. Download the project.
2. Open 'smart_prompt_studio.py' in Python or Thonny.
3. Run the program.
4. Follow the menu options to generate, improve, save, or view prompts.
